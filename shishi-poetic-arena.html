Connect Firebase (one-time setup)

This file ships with no password stored anywhere in the code, on purpose — a static HTML file can never keep a secret, since anyone can read its source. Instead, sign-in is verified by Firebase Authentication on Google's servers, which hashes and salts the password for you. Do this once:
  1. Create a free project at console.firebase.google.com.
  2. Enable Authentication → Sign-in method → Email/Password.
  3. Under Authentication → Users, add user siva80mail@gmail.com and set the password there (e.g. your S@2K11$2K11$#). It is stored server-side only.
  4. Create a Firestore Database (production mode) and paste these rules: 
    rules_version = '2';
service cloud.firestore {
  match /databases/{db}/documents {
    match /poems/{poemId} {
      allow read: if true;
      allow write: if request.auth != null
                   && request.auth.token.email == 'siva80mail@gmail.com';
    }
  }
}
  5. In Project settings → General, copy your web app config and paste it into the FIREBASE_CONFIG object near the top of the <script> tag at the bottom of this file.
  6. Save and reload — the preview banner disappears once it's connected.
A hard refresh always signs the admin out again — sessions are kept in memory only, never written to localStorage, cookies, or the page itself.
